# MedRx Lab 3

UML diagrams, risks, and design for the MedRx Doctor version (Advanced Software Engineering).

## UML Diagrams

PlantUML source files are in `docs/uml/`:

- `usecase.puml` – Use case diagram
- `component.puml` – Component diagram
- `sequence.puml` – Sequence diagram (check interactions)
- `state.puml` – State machine
- `deployment.puml` – Deployment diagram

Render them at [plantuml.com](https://www.plantuml.com/plantuml) or with the PlantUML VS Code extension.
